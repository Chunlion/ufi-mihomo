# ufi-mihomo

中兴 F50 等 UFI-TOOLS 随身 WiFi 的 mihomo（Clash.Meta）透明代理插件套件。

## 组件与职责

| 文件 | 说明 |
|---|---|
| `猫猫TProxy.js` | 统一主插件。Go 辅助内核可用时优先加速高频读取和本地订阅转换；不可用时自动使用 Shell 兼容路径 |
| `开机自启修复.js` | 独立的全插件开机增强器；保留 UFI 原生启动顺序，并提供尾钩快照、故障转移和手动隔离重放 |
| `dist/kano-f50-helper-linux-arm64` | 可选轻量 Go 辅助程序，负责高频状态读取和 YAML、JSON、Base64 封装 YAML/JSON 的订阅格式检查；URI 等完整转换按需调用安装包内的冷 sidecar |

主插件的手动安装、启动、停止、重启和自愈不依赖“开机自启修复”。安装该增强插件后，猫猫和其它插件仍由 UFI 原生启动文件直接执行；末尾增强钩会记录完成状态并同步持久快照，设备提供 `service.d` 时还会安装独立故障转移入口。

## 安装

1. 打开 UFI-TOOLS 管理页（通常为 `http://192.168.0.1:2333/`）→ 插件功能。
2. 上传并提交 `猫猫TProxy.js`。
3. 需要可靠开机启动时，再上传并提交 `开机自启修复.js`，点击“安装 / 修复”。
4. 刷新页面，展开“猫猫”，点击“安装 / 启动核心”。

主插件会在安装和每次关键操作前检查设备 ABI、控制器、mihomo、yq、权限和配置。安装损坏时会先备份配置、模板、订阅和策略数据，再通过受校验的本地安装包或正式下载包修复；提交或启动失败会恢复旧安装目录。

## 状态与排错

运行诊断会区分以下状态：

- `not_installed`：未安装。
- `damaged`：组件、架构、权限或配置预检失败。
- `installed_stopped`：安装完整，核心未运行。
- `running_api_unavailable`：核心进程存在，但控制 API 拒绝、超时、鉴权失败或返回异常。
- `healthy`：核心和控制 API 均正常。

订阅配置检查、核心状态、控制 API 和 Provider 更新分别显示。核心未运行时不会请求 Provider API，也不会把 API 故障误报为配置或订阅地址失效。

配置写入前执行 YAML 解析和结构检查；实际运行状态由热加载或启动后的 API、流量模式和网络策略检查确认，失败时恢复上一份 `config.yaml`。

“订阅设置 → 配置来源”可选择本地模板或订阅原配置。原配置模式只允许一个启用的完整 Mihomo YAML/JSON 订阅，保留其规则、策略组和节点来源；只有节点列表或分享链接的订阅需使用模板模式。更新失败时保留旧配置，不自动切回模板。

上传或编辑 `config.yaml` 后，保存订阅默认只保存设置，勾选应用才会替换自定义配置；“更新订阅”只刷新该配置内的节点来源。自定义配置和订阅原配置的规则、策略组、规则集路径保持不变；保存模板或图形/JS 规则不会自动用模板替换它们，替换需手动点击“应用模板与覆写”。

TProxy 或关闭接管时，运行配置移除 `tun` 段，原参数保存在同一文件的 `x-kano-tun` 中；切回 TUN 时自动恢复，自定义协议栈、MTU 等参数继续保留。IPv6、LAN、TProxy 端口和 DNS 监听的临时适配记录在 `x-kano-network` 中，关闭相应功能后恢复原值。请保留这些字段；旧版已覆盖且没有备份的原值无法恢复。YAML 注释和排版不会保留。

用户配置、模板和 JS 结果中的 DNS 模式、Fake-IP 范围/过滤列表、缓存、嗅探、hosts、自定义面板及普通代理端口均保留。只有开启 DNS 劫持时才适配 DNS 启用状态、监听地址和 IPv6；TProxy 模式临时适配 LAN 监听与接管端口，TUN 模式保留用户的 LAN/端口设置。接管期间 IPv6 与设备设置一致，启用私网定向代理后叠加对应规则。缺少控制 API 或密钥时仍补默认值。接管端口冲突、核心校验或实际监听检查失败时中止应用并进入原有回滚流程。

设备本地转换会先完成全部订阅下载和格式检查，再统一替换节点缓存；任一来源失败时保留原缓存。公网 IPv4、IPv6 订阅地址均可转换。转换 sidecar 丢失时会尝试从已校验安装包恢复，失败后仍可处理 YAML、JSON 及其 Base64 封装。界面和诊断日志会隐藏订阅路径、查询参数及访问密钥。

设备没有 `/tmp` 时属于受支持场景。插件使用 `/data/kano_yq_runtime/tmp` 和 `/data/kano_diag_runtime/tmp`，诊断只检查真实存在的文件系统路径。

## 更新与卸载

原 `_Go` 版用户应停用旧插件后上传 `猫猫TProxy.js`；已有配置和订阅数据不会因插件脚本更新被覆盖。完整卸载请使用猫猫面板中的“完整卸载”，开机启动管理器需在“全插件开机自启修复”中单独卸载。
