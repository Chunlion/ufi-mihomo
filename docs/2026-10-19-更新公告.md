猫猫 TProxy｜10.19 更新

📦 恢复与任务回执
- 完成回执记录退出码与命令输出，释放租约前先校验，避免把未完成的任务当成已完成。
- 响应丢失时按原请求编号补查结果，不重复执行命令。
- 恢复时清理 .output / .receipt 中间文件；原进程已退出才接续 rescue_PID 锁。
- 恢复资格判断补入 age、cp、mv、rm 等进程名，减少“未知持有者”误判。

🔧 安装与卸载
- 允许在“上次任务结果未知”时启动卸载：先回收闲置租约再继续，有活跃任务仍会阻止。
- 安装锁区分活跃与陈旧：PID 不存在且目录干净，才按陈旧锁清理。
- 卸载前先恢复 config.yaml / template 事务，再删除组件；开机项中的 Gist 区块整段移除。

🔐 安全加固
- 控制 API 的 curl 配置改走 stdin，认证头与正文不再进入命令行参数。
- 配置包导入先列目录并校验路径，拒绝绝对路径、..、反斜杠与控制字符。
- JS 覆写禁用 Function / eval 并冻结构造器链；导出 YAML 拒绝 NaN / Infinity。
- 配置导出改为在 /data 私有目录暂存打包，成品 5 分钟后自动删除。

🧹 代码精简
- 删除重复取消判断、失效的 typeof 守卫、allSettled().catch 死捕获，以及两处不可达兜底。
- 合并订阅更新中重复的配置来源读取，每次更新少一次设备 root shell 往返。

💬 文案与菜单
- 全量统一约 400 条提示的句式、标点与术语（组件包、核心、节点来源、运行配置）。
- 修正指向不存在菜单的提示：订阅链接 → 订阅设置，模板与覆写 → 配置与规则。
