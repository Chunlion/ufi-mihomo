# F50 卸载重装实测记录

日期：2026-10-27（北京时间）。环境：已授权的 Android 13 F50，TProxy 模式；修复前代码为 `6e0dcc4`。

通过设备管理页的真实按钮执行两轮卸载、本地组件包重装，以及一次在线更新。测试前保留完整设备副本和经哈希校验的本地用户数据备份，结束后恢复原配置、订阅、Gist 数据和自启状态。私有数据未写入本报告或提交。

## 复现及修复

| 问题 | 设备证据 | 对应代码与修复 |
| --- | --- | --- |
| 卸载、重装后自启按钮仍显示旧状态 | 卸载前自启项为 1 条，重装后为 0 条，按钮仍显示“已开启自启”，`data-boot-state=direct` | [安装完成处理](../猫猫TProxy.js#L2709)和[卸载完成处理](../猫猫TProxy.js#L8674)调用共用的 `refreshBootButtonState`，重新读取设备状态 |
| 切换自启后，解除忙碌状态会覆盖新文案 | 实际已开启，`data-boot-state=direct`，按钮却恢复为“开机自启” | [applyBootButtonState](../猫猫TProxy.js#L10210)同步更新已有 `rawText`，使 `setButtonBusy(false)` 保留新文案 |

## 验证结果

| 路径 | 结果 |
| --- | --- |
| 首轮卸载与本地重装 | PASS；独立检查返回 `UNINSTALL_VERIFIED`；本地重装含上传约 44 秒 |
| 在线下载并更新 | PASS；含下载约 54 秒，结束后任务空闲、临时标记清除 |
| 修复后卸载 | PASS；约 44 秒，无组件、进程或网络接管残留；同一页面按钮变为“开机自启” |
| 修复后同一页面直接重装 | PASS；含上传约 47 秒，按钮与设备的自启关闭状态一致 |
| 自启关闭、开启 | PASS；操作结束后按钮文字和实际状态一致 |
| 原数据恢复 | PASS；运行配置、模式文件及持久用户数据与备份一致；原自启开启状态已恢复 |
| 最终运行状态 | PASS；一个核心进程，API HTTP 200，TProxy 模式，安装锁、操作锁和记录锁均不存在 |

两轮完整卸载重装和一次在线更新均未复现 `F50_OPERATION_BUSY`。本次确认并修复的是上述两个自启显示缺陷；没有据此扩大为所有中断、并发场景均已验证的结论。自启检查依据设备启动文件和界面状态，本轮未重启设备。

本地验证：`node --test --test-reporter=dot tests/tproxy/menu_error_feedback.test.js`，13 项通过；`node --check 猫猫TProxy.js` 通过。生成的安装 Shell 与修复前一致。
