# 猫猫 TProxy 插件文案优化对照表

适用范围：`猫猫TProxy.js`（v9.0.0）。本表逐条列出用户可见文案的原句与优化句，顺序与页面 / 操作流程一致，可直接按“原文 → 优化后”替换。

本次共优化 **423 条**文案（去重后）；所有占位符、变量插值与判断逻辑均未改动。功能名称与菜单文案的后续微调见《功能名称与菜单文案优化.md》，本表已同步为最终文案。

## 一、统一规则

### 1. 结果句式

| 场景 | 句式 | 示例 |
| --- | --- | --- |
| 成功 | `对象 + 已 + 动作`，必要时补结果范围 | 组件已安装并启动，网络接管规则已生效 |
| 部分成功 | `动作已完成 + 具体差额`，不用“部分完成”一笔带过 | 订阅配置正常，部分节点来源更新失败 |
| 失败 | `动作 + 失败：原因；后果 / 下一步` | 组件包下载失败；请检查网络后重试 |
| 警告 | `已完成 + 但 / 仅 + 影响`，说明哪些内容仍有效 | 组件已安装，但订阅地址无效；请填写后启动 |
| 进行中 | `动作 + 中…`，只描述当前实际阶段 | 正在检查配置并重启核心… |

### 2. 标点与格式

- Toast / 单行状态：句末不加句号；并列原因或后果统一用 `；`，不再混用 `，`。
- 对话框正文：使用完整句，句末加 `。`。
- 加载态统一使用中文省略号 `…`，不再出现 `...`。
- 不使用感叹号；引用功能名统一使用 `“”`。
- 数字与单位之间留空格，如 `50 MB`、`8 MB`；计数补单位，如 `3 个节点来源`。

### 3. 术语表

| 统一用词 | 不再使用 | 说明 |
| --- | --- | --- |
| 组件包 | 安装包 | 在线下载或本地导入的 ZIP |
| 核心 | 内核（仅指版本能力时保留“内核”） | 运行中的 Mihomo 进程称“核心” |
| 节点来源 | Provider、来源 | 面向用户的节点供给方 |
| 运行配置 | 配置（指文件时） | 特指 `config.yaml` |
| 网络接管 / 接管规则 | 接管、规则（混用） | iptables / 路由接管 |
| 未 | 没有 | 否定状态统一用“未” |
| 无法读取 | 读取失败 | 状态与原因描述 |
| 未通过 | 异常、失败（校验语境） | 校验结果 |

功能名称保持不变：在线安装/更新、导入组件包、卸载插件、恢复网络、状态与日志、检查修复、流量模式、直连设备、私网定向代理、订阅链接、模板与覆写、图形规则、JS 覆写、节点 DNS 策略、清理缓存、开机自启、订阅请求头、应用模板与覆写、恢复同步事务。
