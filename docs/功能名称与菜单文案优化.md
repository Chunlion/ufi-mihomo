# 功能名称与菜单文案优化说明

范围：`猫猫TProxy.js` 页面内的功能名称、菜单按钮、弹窗标题及相关提示引用。

原则：只处理三类问题——同一功能存在多个叫法、按钮名称与实际动作不符、提示指向页面上不存在的入口。含义清楚且风格一致的名称一律保留；功能行为、按钮位置、颜色与交互均未改动。

本次共调整 **16 处**，逐条说明如下。

## 一、同一功能统一称谓

| 位置 | 原文 | 优化后 | 修改理由 |
| --- | --- | --- | --- |
| 网络设置 → 直连设备卡片标题 | 设备直连 | 直连设备 | 左侧标签页已叫“直连设备”，同一面板内出现“设备直连/直连设备”两种词序；统一为“直连设备”，与“直连设备列表”等表述一致。 |
| 网络设置 → 检查修复 → 查看规则状态说明 | 设备直连项 | 直连设备列表 | 该处指的是直连设备名单，“设备直连项”既不是既有功能名，也不如“列表”准确。 |
| 网络设置 → 流量模式 → QUIC 说明 | 定向私网 | 私网定向代理 | “定向私网”是功能名的截断；标签页、说明文字均使用“私网定向代理”，统一后不会让用户以为是另一个功能。 |
| 订阅与配置 → 菜单按钮与弹窗标题 | 订阅请求头 | 订阅 User-Agent | 该设置实际只写入 User-Agent 一个请求头，原名称会让用户以为可以配置整组请求头；且弹窗内的保存按钮、结果提示一直使用“订阅 User-Agent”，统一为更精确的名称。 |
| 读取订阅 User-Agent 失败提示 | 读取订阅请求头失败 | 读取订阅 User-Agent 失败 | 与上一条同源，避免同一设置在按钮、标题、错误提示中出现两个名称。 |
| 订阅与配置 → 配置与规则 → 配置文件分组 | 导入配置 | 导入配置包 | 实际导入的是 `.tar.gz` / `.tgz` / `.zip` 配置包，确认弹窗与操作名均为“导入配置包”；补全后也能与“导入组件包”明确区分。 |
| 订阅与配置 → 菜单按钮 | 导出配置 | 导出配置包 | 导出产物是配置包，操作名和完成提示均已使用“导出配置包”，按钮与结果保持一致。 |

## 二、动作表述更准确

| 位置 | 原文 | 优化后 | 修改理由 |
| --- | --- | --- | --- |
| 订阅设置 → 保存并更新后的任务名 | 保存更新订阅 | 保存并更新订阅 | 原词缺少连词，容易被读成“保存更新（名词）订阅”；弹窗按钮本身是“保存并更新”，任务名与按钮一致后，进度条标题也更易读。 |
| 直连设备 → 扫描结果行内按钮 | 加 IP / 加 MAC | 添加 IP / 添加 MAC | 与“添加订阅”等按钮统一为完整动词；“加”偏口语，在窄按钮中也容易与其他单字按钮混淆。 |
| 核心与面板 → 快捷按钮 | 安装 / 启动 | 安装/启动 | 全站斜杠均不加空格（如“在线安装/更新”），统一排版写法。 |

## 三、提示指向实际存在的入口

| 位置 | 原文 | 优化后 | 修改理由 |
| --- | --- | --- | --- |
| 模板保存后的提示 | 请点“应用模板与覆写”写入 config.yaml | 请在“配置与规则”中点击“应用模板”写入 config.yaml | 页面上没有名为“应用模板与覆写”的按钮；实际路径是“配置与规则”→“应用模板”。原文会让用户找不到入口。 |
| 无可用节点来源时的提示 | 请先点“订阅链接”填写并保存，或在“模板与覆写”上传包含节点的 template.yaml | 请先点“订阅设置”添加并保存订阅，或在“配置与规则”中上传包含节点的 template.yaml | “订阅链接”“模板与覆写”都不是菜单名：前者实际叫“订阅设置”，后者实际叫“配置与规则”。同时把“填写”改为“添加”，与弹窗内的“添加订阅”按钮对应。 |
| 订阅更新后保留当前配置的提示 | 请手动点击“应用模板与覆写” | 请在“配置与规则”中点击“应用模板” | 同上，提示中的入口名称与页面菜单不一致。 |

## 四、专名大小写

| 位置 | 原文 | 优化后 | 修改理由 |
| --- | --- | --- | --- |
| 流量模式 → DNS 劫持说明 | mihomo DNS 端口 | Mihomo DNS 端口 | Mihomo 是项目专名；同页“TUN 协议栈”说明、版本提示均写作“Mihomo”，统一大小写。 |

## 五、验证

- 仅修改字符串字面量，未改动任何条件判断、按钮绑定、事件处理或功能行为。
- `node --check 猫猫TProxy.js` 通过。
- 修改后的名称与页面实际菜单逐项核对：`订阅设置`、`配置与规则`、`应用模板`、`导入配置包`、`导出配置包` 均可在界面中直接找到。
- 《文案优化对照表.md》与 `.csv` 中对应的 3 条提示已同步为最终文案，避免两份清单出现新旧不一致。
